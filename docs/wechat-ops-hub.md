# 公众号运营总入口

用途：把乐可开源服务号的周检、月排期、草稿预览、反馈回流和 Bark 审核提醒放到同一页，方便长期使用。

## 固定原则

- 先产出草稿，再预览，再人工确认。
- 默认不自动发布，不调用微信修改接口。
- Bark 只负责提醒审核，不负责替代审核。
- 反馈先记台账，再决定是否写进下一篇内容。

## 本地预览

渲染公众号文章：

```bash
npm run wechat:article -- tools/wechat-admin/articles/<file>.md
```

本地预览文章：

```bash
npm run wechat:article:preview -- tools/wechat-admin/articles/<file>.md
```

预览会打印一个本地 `file://` 地址，直接在浏览器打开即可。页面顶部还有「一键复制富文本」按钮，复制后再去公众号后台粘贴。

对应这篇文章的发布清单：

- [公众号发布清单](../tools/wechat-admin/articles/2026-08-10-operations-toolchain-publish-checklist.md)

## 周检清单

每周建议按这个顺序看：

1. 公众号菜单是否需要调整。
2. 关键词回复和关注回复是否要补充。
3. 最近是否有产品进展可发。
4. 上篇文章的数据、留言或反馈是否需要跟进。
5. 是否需要准备一篇新的推文草稿。

常用参考文件：

- [内容计划](../tools/wechat-admin/content-plan.md)
- [反馈台账](./wechat-feedback-ledger.md)
- [公众号文章初稿目录](../tools/wechat-admin/articles/README.md)

## 月排期清单

每月建议先看两篇主文：

1. 产品进展
2. 工程复盘

如果当月有新功能、小版本、活动或服务更新，再补一篇短更新。

参考：

- [内容计划](../tools/wechat-admin/content-plan.md)
- [公众号运营 Bark 交接计划](./superpowers/plans/2026-08-10-wechat-automation-bark-handoff.md)

## Bark 审核提醒

当自动化生成草稿后，Bark 提醒建议固定包含：

- 文章标题
- 是否需要补图
- 是否需要改摘要
- 是否进入手动发布

建议文案模板：

```text
公众号待审核
标题：{{title}}
状态：草稿已生成，请确认标题、摘要、配图和发布时间。
```

## 反馈回流

每周把反馈台账更新一次：

- 有反馈就补来源、问题类型、原始反馈和下次动作。
- 没有反馈就写 `本周暂无反馈`。
- 如果反馈能直接变成下一篇文章素材，就顺手记到选题里。

## 目前建议的执行节奏

| 场景 | 先做什么 | 后做什么 |
| --- | --- | --- |
| 周检 | 看菜单、关键词、反馈台账 | 决定是否补一篇短更新 |
| 月排期 | 看产品进展和工程复盘 | 生成草稿并发 Bark |
| 发文前 | 打开本地预览 | 人工确认后再发布 |
