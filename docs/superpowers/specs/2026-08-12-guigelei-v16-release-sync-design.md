# 归个类 v1.6 发行同步设计

## 目标

修复官网重复的更新记录入口，让归个类页面的版本、下载、统计和常见问题全部由发行目录驱动，并将已验证的 v1.6.0 DMG 同步到唯一公开发行仓库 `lekeopen/guigelei-releases`。

## 设计

- 首屏只保留“下载 macOS 版”，底部保留唯一“更新记录”链接。
- 页面文案、下载统计 tag 和 FAQ 使用 `product.version`，不再写死 v1.5.0。
- 产品集成测试验证仓库、tag、附件命名和 URL 的一致性，不冻结某个版本。
- 官网修复通过 PR 上线后，在 `guigelei-releases` 发布只含已校验 DMG 的 v1.6.0 正式 Release，然后手动触发发行监控。
- 任一测试、CI、预览、部署或线上检查失败时停止后续发布。

## 验收

1. 归个类页面只有一个正式 Release 更新记录链接。
2. v1.6.0 数据进入目录后，完整 `npm run verify` 通过。
3. 线上展示 v1.6.0，DMG URL、字节数和 SHA-256 与 GitHub Release 一致。
4. 不执行百度、IndexNow 或其他搜索平台提交。
