# Site V1.4 Search Indexing and SEO Operations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a China-first, testable SEO operations workflow that validates production, supports Baidu URL submission and Bing IndexNow, prepares all three webmaster-platform verification paths, governs keywords and internal links, and records recurring evidence without storing secrets.

**Architecture:** Keep `scripts/seo-routes.mjs` as the only public-route source and add focused modules under `tools/seo-ops/src`. Pure inventory and payload functions remain separate from network clients and the CLI. CI runs deterministic tests and read-only production inspection only; authenticated submissions remain explicit operator actions.

**Tech Stack:** Node.js 24 ESM, built-in `node:test`, Cheerio, existing Vite/React prerender pipeline, GitHub Actions.

## Global Constraints

- Baidu is the primary search platform; Google and Bing remain first-class compatibility targets.
- Do not replace React + Vite or create a second manually maintained public URL list.
- Only published canonical URLs may be inspected or submitted.
- Tokens and private response data must never enter Git, logs, generated reports, or command output.
- Every external write defaults to dry-run and requires an explicit `--execute` flag.
- Google Search Console uses ownership verification and sitemap submission only; do not use Google Indexing API for ordinary pages.
- Provider acceptance means accepted for processing, not indexed.
- Login, CAPTCHA, QR code, and final platform confirmation remain user-operated.
- V1.4 remains incomplete until engineering acceptance and all three manual platform gates pass.
- Do not add new runtime dependencies.

---

## File Map

- `tools/seo-ops/src/inventory.mjs`: parse and normalize canonical URLs; calculate notification deltas.
- `tools/seo-ops/src/safety.mjs`: redact secrets and classify retryable failures.
- `tools/seo-ops/src/request.mjs`: bounded retry wrapper with injectable fetch and delay.
- `tools/seo-ops/src/providers.mjs`: construct Baidu and IndexNow requests without sending them.
- `tools/seo-ops/src/state.mjs`: read and write redacted notification state outside tracked source data.
- `tools/seo-ops/src/inspect.mjs`: perform read-only production SEO checks.
- `tools/seo-ops/src/report.mjs`: combine inspection results and sanitized platform metrics into Markdown.
- `tools/seo-ops/src/cli.mjs`: expose inventory, inspect, submit, and report commands.
- `scripts/prerender.mjs`: optionally inject public webmaster verification meta values.
- `config/seo-keywords.json`: versioned page-intent and internal-link governance map.
- `docs/seo/`: operator guide, publishing checklist, report template, and platform acceptance record.
- `tests/seo-ops-*.test.mjs`: focused unit and integration tests.

## Official Protocol References

- Baidu Search Resource Platform link submission: `https://ziyuan.baidu.com/linksubmit/url/`
- IndexNow protocol: `https://www.indexnow.org/documentation`
- Google Indexing API eligibility: `https://developers.google.com/search/apis/indexing-api/v3/using-api`
